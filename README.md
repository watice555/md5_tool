# MD5 工具说明

这个目录里有一个用于计算字符串 MD5 的 Python 脚本：`main.py`。

## 运行方式

### 方式 1：单次计算

```bash
python main.py 123
```

输出示例：

```bash
202cb962ac59075b964b07152d234b70
```

### 方式 2：循环输入

```bash
python main.py
```

然后按提示输入内容：

```bash
请输入要计算 MD5 的内容: 123
202cb962ac59075b964b07152d234b70
请输入要计算 MD5 的内容: hello
5d41402abc4b2a76b9719d911017c592
```

## 退出方式

循环模式下可使用以下方式退出：

- 按 `Ctrl+C`
- 或按 `Ctrl+Z` 后回车
